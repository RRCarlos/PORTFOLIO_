## 🎨 Paleta de Colores y Diseño

### Colores
- **Primario**: `#0A1628` (Azul profundo - fondos oscuros)
- **Secundario**: `#6366F1` (Violeta eléctrico - acentos, botones)
- **Acento**: `#22D3EE` (Verde lima - highlights, enlaces)
- **Fondo claro**: `#FAFAFA` (Blanco cálido)
- **Texto**: `#1E293B` (Casi negro)

### Tipografía
- **Headlines**: Inter 700 (48-64px)
- **Subheadings**: Inter 600 (24-32px)
- **Body**: Inter 400 (16-18px, line-height 1.6-1.7)
- **Mono** (opcional): JetBrains Mono (14px)

### Animaciones
- **Fade-in**: Opacity 0→1, translateY(20px)→0, 500ms ease-out
- **Stagger**: Delay de 100ms entre elementos de grid
- **Hover**: translateY(-8px), sombra intensificada, 300ms ease-out

## 📋 Glosario (Castellano Correcto)

| Término Original | Término Recomendado | Contexto |
|------------------|---------------------|----------|
| Hero | Sección principal / Portada | Primera sección visible de la página |
| Headline | Titular | Frase principal que comunica valor |
| Subheadline | Subtítulo | Texto secundario bajo el titular |
| CTA (Call to Action) | Botón de acción / Llamada a la acción | Botón que invita a realizar una acción |
| Mockup | Maqueta / Prototipo visual | Representación visual del diseño |
| Cards | Tarjetas | Contenedores visuales para proyectos |
| Hover effects | Efectos al pasar el cursor | Animaciones al situar el cursor sobre elemento |
| Grid | Cuadrícula / Rejilla | Disposición en forma de tabla/grid |
| Badges | Insignias / Distintivos | Pequeños elementos visuales identificativos |
| Timeline | Línea de tiempo | Representación cronológica visual |
| Responsive | Adaptable / Diseño adaptable | Se adapta a diferentes tamaños de pantalla |
| Dark mode | Modo oscuro | Tema con fondos oscuros |
| Scroll | Desplazamiento | Acción de bajar la página |
| Fade-in | Aparecer gradualmente | Animación de entrada suave |
| Stack tecnológico | Tecnologías / Herramientas | Conjunto de tecnologías utilizadas |
| Landing page | Página de aterrizaje / Página principal | Página web enfocada a una meta específica |
| No-code | Sin código | Herramientas que no requieren programar |
